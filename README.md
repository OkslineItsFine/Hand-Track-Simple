# Hand-Track

A real-time hand tracking visual effects project built with Python,
OpenCV, and MediaPipe.

## Features

- Real-time hand tracking
- Two-hand portal
- 4-point responsive portal
- Gesture-based effect switching
- Multiple visual effects
- Webcam support

## Requirements

- Python 3.10+
- Webcam

## Installation

Clone the repository:

```bash
git clone https://github.com/OkslineItsFine/Hand-Track-Simple.git
cd Hand-Track-Simple
pip install -r requirements.txt
python main.py
```
